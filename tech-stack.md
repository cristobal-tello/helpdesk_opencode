# Tech Stack

## Frontend

- React with TypeScript
- Vite (dev server + build)
- Tailwind CSS v4 (Tailwind UI styles)
- React Router v7

## Backend

- Express 5 with TypeScript, Bun runtime
- Better Auth (email/password, database sessions)

## Database

- PostgreSQL 16

## ORM

- Prisma 6

## AI

- Claude API (Anthropic) for ticket classification, summaries, and suggested replies

## Email

- SendGrid or Mailgun for outbound replies and inbound webhooks

## Deployment

- Docker + cloud provider (AWS, Railway, Fly.io, etc.)

## AI Dev Tools

- Better Auth skill installed for AI-assisted auth integration
